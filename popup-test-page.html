🧪 부정클릭 팝업 테스트 페이지

테스트 유형 선택

📋 테스트 방법

위의 버튼을 클릭하여 각각의 부정클릭 경고 팝업을 확인할 수 있습니다.

팝업은 좌측상단에 나타나며, 각 단계별로 다른 경고 레벨을 보여줍니다.

🔍 팝업 확인 사항

  • 팝업이 좌측상단에 올바르게 표시되는가?
  • 애니메이션이 부드럽게 작동하는가?
  • 닫기 버튼이 정상적으로 작동하는가?
  • 내용이 읽기 쉽게 표시되는가?
  • 진행바가 올바르게 작동하는가?

🚨 경고 레벨별 특징

  • 1단계 (노란색): 중복접속 경고 - 경미한 의심
  • 2단계 (주황색): 과도한 클릭 경고 - 중간 수준 의심
  • 3단계 (빨간색): 심각한 패턴 경고 - 높은 수준 의심
