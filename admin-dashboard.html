GeoLocation 서비스 안내

• 위치 정보는 네이버 클라우드 플랫폼의 GeoLocation 상품을 이용합니다.

• GeoLocation 서비스는 모바일 네트워크에 대한 주소를 제공하지 않으며, PC로 접근한 광고 접속의 경우에만 주소 정보를 제공합니다.

• PC가 모바일 네트워크를 이용하거나 프록시 등을 사용할 경우 위치 정보가 다를 수 있습니다.

• 참고용으로만 이용해야 합니다.

• 베타 서비스로 GeoLocation 상품 상태와 고객 이용 후기에 따라 무료 제공 범위와 대상이 조정될 수 있습니다.

• 위치 상세 정보는 '동'까지만 제공되며, 지도에는 대표 위치(예: 주민센터)가 표시됩니다.

차단관리 안내

  • IP 차단/해제 시 해당 계정과 자동 동기화됩니다.
  • 잠금 기능은 현재 상태를 유지하며, 여러 계정 연결 시 기준 계정에 따릅니다.
  • 차단된 상태에서 잠금 시 자동 해제되지 않으며, 해제된 상태에서 잠금 시 다시 차단되지 않습니다.
  • 잠금 상태가 기준 광고 계정과 반대일 경우 자동관리 시스템 잠금은 자동 해제됩니다.

  • 차단/해제: IP 차단 및 해제를 직접 할 수 있는 기능이며, 최대 수분이 소요될 수 있습니다.
